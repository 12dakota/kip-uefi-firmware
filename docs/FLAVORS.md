# Firmware flavors

| Flavor | Board | Image |
|---|---|---|
| snappy-stock | SNAPPY (APL, e.g. HP 14-class) | official Full ROM |
| snappy-logo | SNAPPY | official + coreboot_logo.bmp |
| snappy-elan-dxe | SNAPPY | experimental payload splice |
| banon-stock | BANON (Braswell, Acer CB3-532) | official Full ROM |
| banon-logo | BANON | official + coreboot_logo.bmp |

Do not flash SNAPPY ROM on BANON or the reverse.

Setup UI is Tianocore. USB mouse may work (UsbMouseDxe).
Built-in Elan is not Click BIOS / Visual BIOS.
